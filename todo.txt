   - Email : mise en minuscules, suppression des espaces
   - Ne pas produire de json avec une liste vide.

     - ChromeExtension/ (popup, content, manifest…)
     - rof-signup.js
     - Le fichier de configuration des chemins (voir point 2)

2. Fichier de configuration des chemins (paths.config.json)
   - Créer un fichier paths.config.json à la racine, référencé par server.js et rof-signup.js.
   - Contenu minimal :
     {
       "watchDir": "C:/chemin/vers/dossier/pdfs",
       "convertedDir": "<watchDir>/converted",
       "erroredDir":   "<watchDir>/errored"
     }
   - converted/ et errored/ sont des sous-répertoires du dossier surveillé.
   - Les scripts lisent ce fichier au démarrage au lieu d'utiliser des chemins codés en dur.

3. Script d'initialisation (setup.bat + setup.js) — Windows uniquement
   - setup.bat ouvre la boîte de dialogue système native via PowerShell
     (System.Windows.Forms.FolderBrowserDialog) :
       * accès à l'arborescence complète du système
       * bouton "Créer un nouveau dossier" inclus nativement
   - Le chemin sélectionné est passé en argument à node setup.js.
   - setup.js écrit paths.config.json et crée converted/ et errored/ si absents.
   - Aucune dépendance supplémentaire — 100% natif Windows.

4. Script de build / packaging
   - Générer un zip propre : npm run build (ou script dédié).
   - Le zip est nommé avec la version : rof-parser-v1.0.0.zip (semver).
   - La version est lue depuis le champ "version" de package.json — un seul endroit
     à mettre à jour à chaque livraison.
   - Inclure uniquement les fichiers nécessaires à la production (voir point 1).
   - Le zip contiendra un README d'installation indiquant :
       1. npm install --omit=dev
       2. setup.bat       (sélection du dossier, première installation uniquement)
       3. npm start       (lance le serveur)
       4. Charger ChromeExtension/ dans Chrome (mode développeur)


── GESTION DES DOUBLONS EXCEL 🚧 ─────────────────────────────────────────────

Actuellement rof-signup.js ajoute toujours une nouvelle ligne dans le fichier Excel,
sans vérifier si le licencié existe déjà.

1. Clé d'unicité : Nom + Prénom + Date de naissance
   - Avant d'écrire une ligne, chercher une ligne existante avec les mêmes trois valeurs.
   - Si trouvée → mettre à jour les champs de la ligne existante (upsert).
   - Si non trouvée → ajouter une nouvelle ligne (comportement actuel).

2. Points d'attention
   - La comparaison doit être insensible à la casse et aux espaces superflus
     (les noms sont normalisés en majuscules, mais mieux vaut défensif que désolé).
   - Logger clairement : "Mise à jour de X Y (existant)" vs "Ajout de X Y (nouveau)".
